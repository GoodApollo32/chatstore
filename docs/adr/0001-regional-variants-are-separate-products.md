# Regional variants are separate Master Products

Part numbers that differ only by a region code (e.g. HP `…#ABC` for Canada vs `…#ABA` for the US) are treated as different Master Products and are never merged. The region code decides the keyboard layout, power cord and packaging language, so merging them would let a US-configured unit be quoted to a Canadian customer. The cost is that search shows near-duplicate products, which we accept. Splitting merged products apart later would be much harder than merging separate ones.
